# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML and CSS, delegated to the existing shared Nginx publishing repository. Individual pages remain self-contained and add no repository-wide framework.

## Users

Technical creators, independent developers, and solo builders who need concise, shareable references while working with coding agents and command-line tools.

## Product Purpose

Publish small, durable reference pages that explain a practical workflow clearly enough to understand, copy, and use without additional context.

## Operating Context

Readers arrive through a shared URL, commonly on desktop while configuring developer tools. Pages may include shell commands, configuration snippets, downloadable scripts, and links to primary documentation.

## Capabilities and Constraints

- Each page lives at a stable slug under `pages.jonp.dev` or `pages.illustrious.dev`.
- Pages are public; no credentials, private account details, customer data, or internal infrastructure may appear.
- Content must distinguish public examples from real secret values.
- Permanent pages must be responsive, keyboard accessible, usable with reduced motion, and functional without a JavaScript framework.

## Evidence on Hand

The user supplies each page's subject and required content. Do not invent usage statistics, customers, endorsements, or security guarantees.

## Product Principles

- Give the useful answer before background.
- Make secure behavior the easiest behavior to copy.
- Prefer exact commands and explicit boundaries over vague advice.
- Keep each page focused enough to scan during active work.
